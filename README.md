# 시트모아 · Sheet Moa

HTML, CSS, JavaScript로 만든 CSV / Excel 파일 병합·분리 및 좌표 지도 도구입니다. 파일 데이터는 서버로 전송하지 않고 브라우저에서 처리합니다.

## 실행

저장소를 다운로드하거나 복제한 뒤 `dist/index.html`을 브라우저로 열면 됩니다. 별도 설치나 서버 없이 오프라인에서도 실행할 수 있습니다. `dist` 안의 파일과 `vendor` 폴더를 함께 보관하세요.

## 기능

- **파일 병합**: CSV / XLSX 여러 파일을 올리고 같은 열 제목을 맞춰 데이터를 아래로 이어 붙입니다.
- **데이터별 분리**: 한 파일에서 기준 열을 선택해 같은 값을 가진 행끼리 나눕니다.
- **날짜별 분리**: 날짜 열을 연도별(`2026`) 또는 연월별(`2026-01`)로 나눕니다. 다른 해의 같은 달은 별도 그룹입니다.
- **다운로드**: CSV / XLSX 선택, 개별 다운로드, 분리 파일 전체 ZIP 다운로드를 지원합니다.
- **미리보기**: 처음 100행과 최대 30열을 표시하며 다운로드에는 전체 데이터를 포함합니다.
- **한글 CSV**: UTF-8 / EUC-KR 입력, UTF-8 BOM 출력과 문자열의 앞자리 0을 지원합니다.

## 날짜 분리 사용법

1. 상단 **파일 분리** 메뉴를 엽니다.
2. CSV 또는 XLSX 파일 하나를 올립니다.
3. Excel 시트와 날짜가 들어 있는 기준 열을 선택합니다.
4. 분리 방식을 **날짜 · 연도별** 또는 **날짜 · 연월별**로 선택합니다.
5. 필요하면 텍스트 날짜 순서를 월/일/년 또는 일/월/년으로 지정합니다.
6. **데이터별 파일 분리**를 누른 후 개별 파일 또는 전체 ZIP을 받습니다.

Excel 날짜 셀과 `2026-01-15`, `2026.01.15`, `20260115` 등 텍스트 날짜를 지원합니다. 날짜를 읽을 수 없는 행은 **날짜 확인 필요**, 빈 날짜는 별도 빈 값 그룹에 포함합니다. 원본 날짜 표기는 유지합니다.

## 위치 지도 사용법

1. **파일 분리**에서 데이터를 나눈 뒤 **분리 결과를 지도에서 확인**을 누릅니다.
2. 또는 **위치 지도**에서 CSV / XLSX 여러 파일을 직접 추가합니다. 첫 행은 제목으로, Excel은 첫 번째 시트를 읽습니다.
3. 위도·경도 열과 지점 이름 열을 선택하고 **지도에 표시**를 누릅니다.
4. 그룹별 표시 여부를 바꾸거나 지도 지점·목록의 **위치 보기**를 눌러 원본 행 정보를 확인합니다.
5. 좌표 확인이 필요한 행을 따로 보고, 선택 그룹의 전체 검증 결과를 CSV로 저장할 수 있습니다.

WGS84 십진수 위도·경도를 사용합니다. 빈 좌표는 0으로 바꾸지 않으며, (0,0)은 유효한 좌표입니다. 주소 자동 검색 및 TM/UTM 좌표 변환은 포함하지 않습니다. 지도는 최대 5,000개 지점, 목록은 페이지마다 50행을 표시하며 다운로드에는 선택 그룹의 전체 행이 포함됩니다.

분리 결과 전달은 브라우저의 IndexedDB를 사용합니다. 최근 전달 결과 하나를 보관하며 24시간 후에는 가져올 수 없습니다. 지도 페이지의 **초기화**로 저장 데이터를 삭제할 수 있습니다.

배경지도는 온라인 웹사이트 또는 로컬 웹서버에서 실행할 때 인터넷으로 불러옵니다. HTML 파일을 직접 열면 배경지도 요청 없이 지점과 목록을 사용할 수 있습니다. OpenStreetMap에는 표시 영역에 필요한 타일 요청을 전송하며 파일의 전체 행·상세 정보는 전송하지 않습니다.

## 구성

```text
dist/
  index.html       # 병합 페이지
  app.js           # 병합 화면 및 다운로드
  core.js          # 열 매칭, CSV 출력
  split.html       # 분리 페이지
  split.js         # 분리 화면 및 다운로드
  split-core.js    # 그룹 분리, 날짜 해석, ZIP 생성
  map.html         # 위치 지도 페이지
  map.js           # 지도, 필터, 상세 정보, 좌표 CSV
  map-core.js      # 좌표 파싱 및 검증
  map-bridge.js    # 분리 결과의 임시 전달
  map.css          # 지도 화면 스타일
  style.css        # 반응형 화면
  README.txt       # 상세 사용 안내
  vendor/
    xlsx.full.min.js
    LICENSE
check.cjs          # 핵심 병합 검증
browser-check.cjs  # 병합 화면 검증
split-check.cjs    # 분리 화면 검증
date-check.cjs     # 날짜별 분리 검증
map-check.cjs      # 지도 및 분리 결과 전달 검증
```

## 검증

Node.js 20 이상에서 핵심 검증은 추가 설치 없이 실행할 수 있습니다.

```sh
npm test
```

브라우저 검증에는 Playwright와 Microsoft Edge가 필요합니다.

```sh
npm install
npm run test:browser
```

브라우저 검증은 파일 업로드, 결과 미리보기, CSV / XLSX 다운로드, 여러 시트, 파일명 충돌, 날짜별 분리, 설정 변경, 모바일 화면 및 좌표 지도 기능을 확인합니다. 지도 검증은 임시 로컬 서버를 자동 실행하고 배경 타일을 모의 응답으로 대체합니다. 결과물은 `test-results/`에 생성됩니다.

## 처리 규칙과 제한

- 셀의 표시 값을 사용하며 서식, 수식 자체, 매크로, 차트는 유지하지 않습니다.
- 빈 행은 생략하고, 누락된 열의 값은 빈칸으로 채웁니다.
- CSV에서 수식으로 해석될 수 있는 문자열에는 작은따옴표를 앞에 추가합니다.
- XLSX 저장 한도는 제목 행 포함 1,048,576행 / 16,384열입니다.
- ZIP은 무압축 방식으로 최대 4GB / 65,535개 파일을 지원합니다.
- 처리 가능한 파일 크기는 브라우저 메모리에 따라 달라집니다.

## 외부 라이브러리

SheetJS Community Edition 0.20.3이 포함되어 있습니다. 해당 라이브러리의 Apache-2.0 라이선스는 `dist/vendor/LICENSE`에서 확인할 수 있습니다.

지도 표시에는 Leaflet 1.9.4를 사용합니다. 라이선스는 `dist/vendor/leaflet-LICENSE`에 포함되어 있으며 배경지도에는 OpenStreetMap contributors 저작자 표시가 적용됩니다.
